# Contributing to BookLooky

Thank you for considering contributing to BookLooky!

## Our Philosophy
BookLooky aims to provide free, spoiler-free, objective book content ratings. The core Looky Rating System (LRS) methodology is managed by Jon Penneman. We welcome contributions that improve documentation, fix bugs, support library integrations, and help with marketing/outreach.

## What We Welcome
- Bug reports
- Documentation improvements and corrections
- Library / school / catalog integration ideas and help
- Marketing materials, outreach, and community promotion
- General feedback on user experience (non-rating related)

## What We Do Not Accept at This Time
- Changes to core rating methodology or LRS scoring logic
- Major feature changes to how ratings are calculated or presented

## How to Contribute

### Bug Reports & Discussions
- Open an issue in the [booklooky-official-lrs-rater](https://github.com/TheWootini/booklooky-official-lrs-rater) repository

### Documentation & Other Contributions
- Fork the repository and submit a pull request
- For larger changes, open an issue first to discuss

### Library Integrations or Marketing Help
- Open a GitHub issue or use the contact form on [booklooky.com](https://booklooky.com)

## Process
All contributions are reviewed and must be approved by Jon Penneman (Project Lead) before merging.

## Code of Conduct
We expect respectful and constructive communication. Harassment or toxic behavior will not be tolerated.

## Questions?
- Open a GitHub issue in the repository above
- Use the contact form on [booklooky.com](https://booklooky.com)

We appreciate your help in making BookLooky better for readers, authors, and libraries!
