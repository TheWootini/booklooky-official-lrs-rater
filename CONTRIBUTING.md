# Contributing to BookLooky Official LRS Rater

Thank you for considering contributing to this repository.

## Contributor License Agreement

**All pull requests require a signed CLA.** After you open a PR, the CLA
Assistant bot will comment with signing instructions. Comment exactly:

```text
I have read the CLA Document and I hereby sign the CLA
```

See [CLA.md](CLA.md). Until the CLA is signed, we cannot merge.

Unless you state otherwise:

- Software source code is contributed under the [MIT License](LICENSE.md)
- Documentation is contributed under [CC BY 4.0](docs/LICENSE.md)

The CLA does not grant rights in BookLooky brand names or badge artwork.

## Our Philosophy

BookLooky aims to provide free, spoiler-free, objective book content ratings
for readers. The core Looky Rating System (LRS) methodology is managed by Jon
Penneman. We welcome contributions that improve documentation, fix bugs,
support library integrations, and help with marketing/outreach.

## What We Welcome

- Bug reports
- Documentation improvements and corrections
- Library / school / catalog integration ideas and help
- Marketing materials, outreach, and community promotion
- General feedback on user experience (non-rating related)

## What We Do Not Accept at This Time

- Changes to core rating methodology or LRS scoring logic
- Major feature changes to how ratings are calculated or presented

## How to Contribute

### Bug reports, questions, and ideas

Open a GitHub issue and pick the matching template:

| Label | Use for |
|---|---|
| `bug` | Something in this rater is broken |
| `enhancement` | A feature or docs change |
| `question` | How to run or integrate this rater |
| `docs` | Documentation-only work (maintainers may add this) |

The Project Lead reviews new issues and aims to **acknowledge within two
business days**. Bugs are defects in this codebase. Product, billing, and
booklooky.com catalog questions go to [booklooky.com](https://booklooky.com).
See [SUPPORT.md](SUPPORT.md).

For larger changes, open an issue first to discuss.

### Documentation and code

1. Fork the repository.
2. Create a branch and make your change.
3. Open a pull request. Sign the CLA when the bot asks.
4. Update docs or tests when the change needs them (see [CODE REVIEW.md](CODE%20REVIEW.md)).

### Library integrations or marketing help

Open a GitHub issue or use the contact form on [booklooky.com](https://booklooky.com).
