# Security Policy

## Supported Versions

Only the latest released version of the BookLooky Official LRS Rater is supported for security updates.

## Reporting a Vulnerability

We take security seriously. If you discover a security issue, please report it privately.

**Preferred method:**  
Email Jon Penneman directly through the contact form on https://booklooky.com (select “Security” or “Support”).

**What to include in your report:**
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (if known)

We will acknowledge receipt within 48 hours and aim to provide a timeline for resolution within 7 days. We appreciate responsible disclosure and will credit reporters (unless anonymity is requested).

## Security Updates

Security fixes will be released as soon as they are verified. We follow semantic versioning and will note security-related changes in release notes.

Thank you for helping keep BookLooky secure.
